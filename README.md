# CIA Roleplay V2.2 — Access Code Portal

موقع لعب أدوار خيالي، فيه بوابة دخول بالاسم والكود، استمارة QCM، إرسال طلبات للإدارة، وقائمة لإدارة أكواد الدخول والرتب.

## الملفات
- `index.html` — الواجهة وبوابة الدخول.
- `styles.css` — التصميم المتجاوب والمؤثرات.
- `app.js` — الاختبار، التقديم، ولوحة الإدارة التي تستعمل RPC.
- `config.js` — رابط Supabase ومفتاح anon/public فقط.
- `supabase.sql` — الجداول والدوال وسياسات صلاحيات قاعدة البيانات.

## إصلاحات V2.2
- إصلاح طبقات التصميم التي قد تعترض النقر والكتابة في خانات الدخول.
- زر CIA ADM يضع كود الإدارة `1937` في خانة الكود؛ ما زال يلزم الاسم.
- رسالة واضحة داخل بوابة الدخول إذا لم تتم تهيئة Supabase، بدل إظهار تنبيه أعلى الصفحة.
- لا توجد صلاحية إدارة تجريبية محلية غير آمنة؛ الأكواد لا تُقبل فعلياً إلا بعد إعداد قاعدة البيانات.

## الإعداد والنشر
1. أنشئ مشروعاً في [Supabase](https://supabase.com/dashboard).
2. افتح **SQL Editor**، والصق محتوى `supabase.sql` كاملاً، ثم نفّذه. إذا كنت قد شغّلت النسخة القديمة من SQL، شغّل الملف كاملاً حتى تنضاف جداول ودوال V2.1.
3. من **Project Settings → API** انسخ **Project URL** و **anon/public key** (لا تستعمل `service_role`). ضع القيم في `config.js`.
4. ارفع الملفات إلى جذر مستودع GitHub Pages أو استعمل استضافة ملفات ثابتة. يجب أن يبقى `index.html` في الجذر.
5. افتح الموقع واختبر كود الإدارة `1937`، ثم أنشئ كود عضو من لوحة الإدارة، وسجّل الخروج، وجرب كود العضو.

## طريقة الاستخدام
- كل زائر يبدأ بصفحة الاسم وكود الدخول.
- كود العضو يجب أن يكون قد أنشأته الإدارة مسبقاً. بعد الدخول يقدر يجاوب QCM ويصيفط طلب الانضمام.
- كود الإدارة `1937` يفتح لوحة الإدارة. يمكن مراجعة الطلبات وقبولها/رفضها وإنشاء الأكواد وتغيير رتبها وإيقافها/حذفها.
- الرتب `admin` و`staff` عندها صلاحية لوحة الإدارة. الأكواد الرئيسية `1937` محمية من الحذف أو تغيير الرتبة داخل الواجهة.
- إذا كان كود استُعمل في طلب، فإن زر الحذف يوقفه حتى تبقى الطلبات القديمة مرتبطة به.

## تنبيه أمني مهم
هذا نظام مجتمع/Roleplay، وليس نظام هوية حقيقي. كود `1937` هو مفتاح إدارة مشترك كما طلبت؛ أي شخص يعرفه يقدر يستعمل صلاحيات الإدارة. لا تنشره علناً ولا ترسله للأعضاء. إذا أصبح الموقع عاماً، غيّره إلى رمز قوي وفريد قبل إطلاقه. الدوال تتحقق من صلاحية الكود على قاعدة البيانات، لكن هذا المفتاح المشترك لا يعادل حسابات فردية مع MFA أو تحديد محاولات الدخول. لا تخزن معلومات حساسة في الموقع.

## ملاحظات
- الموقع لن يتصل بقاعدة البيانات حتى تضع بيانات Supabase الصحيحة وتشغّل SQL.
- نتيجة QCM تُرسل مع الطلب وتستعمل للتقدم داخل لعب الأدوار فقط؛ لا تعتبر اختباراً رسمياً أو مقاومًا للغش.
- المشروع خيالي مستقل ولا يمثل وكالة الاستخبارات المركزية الأمريكية أو أي جهة حكومية.
